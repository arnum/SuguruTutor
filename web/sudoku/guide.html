The order in practice

  1. Scan box by box for hidden singles, then row by row and column by column, until nothing more happens.
  2. Look for locked candidates: a number that in a box can only go in one row or column, or in a line only within one box.
  3. Write the possible numbers in pencil, and look for pairs and triples in every row, column and box.
  4. Find numbers with two places in a house (X-wing and the like) and cells with two options (XY-wing), and see whether they can be chained. Start with one number at a time.
  5. Only when nothing else works: assume a number and follow it. Start with just that one number, then all numbers, and finally try both ways.

In the game, a puzzle's difficulty is measured as effort: the heaviest step plus an addition for how many heavy steps there are. The level shown for each technique below is the technique's place from easy to hard, not the puzzle's difficulty. All examples were found in real puzzles from the game's generator, and the texts are the same as the game's hints show.
